# 🎧 Focus Lounge (অ্যাম্বিয়েন্ট সাউন্ড ও পোমোডোরো স্টুডিও)

একটি আধুনিক, মিনিমালিস্টিক ওয়েব অ্যাপ্লিকেশন যা কাজে মনোযোগ ও উৎপাদনশীলতা বাড়াতে সহায়তা করে।

## ✨ মূল ফিচারসমূহ
1. **পোমোডোরো টাইমার:** Focus (25m), Short Break (5m), Long Break (15m)।
2. **অ্যাম্বিয়েন্ট সাউন্ড মিক্সার:** বৃষ্টি, অগ্নিকুণ্ড, বাতাস, ঢেউ, ব্রাউন নয়েজ এবং ধ্যান ড্রোন (৪৩২Hz)।
3. **জেন মোড:** সম্পূর্ণ ডিস্ট্র্যাকশন-ফ্রি ফুল স্ক্রিন ফোকাস ভিউ।
4. **স্মার্ট কিবোর্ড শর্টকাট:**
   - `Space` - টাইমার শুরু বা পজ করা
   - `R` - টাইমার রিসেট করা
   - `Z` - জেন মোড টগল
   - `M` - সব সাউন্ড মিউট/চালু করা
5. **লোকাল স্টোরেজ:** আপনার সেশন ও ভলিউম প্রিফারেন্স ব্রাউজারে সংরক্ষিত থাকে।
